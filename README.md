# Purpur End

Purpur End is a Minecraft plugin that creates a custom End dimension filled with Purpur blocks, featuring unique structures, entities, and commands. This plugin enhances the vanilla End experience by introducing new challenges and loot mechanics, making it a perfect addition for servers looking to add variety and excitement to their gameplay.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. **Generate the Purpur End Dimension**:
   - Use the command `/PurpurEnd` to manage loot in the Purpur End dimension.
   - Use the command `/PurpurPortal` to generate a custom End Portal.

2. **Explore the Purpur End Dimension**:
   - Enter the Purpur End dimension through the custom End Portal.
   - Fight against unique entities like Ender Creepers, Ender Ghasts, Brute Piglins, and Netherite Zombies.
   - Discover new structures and loot.
